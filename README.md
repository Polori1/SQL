# Persona-Oficina

Repositorio que sirve como punto de partida para la resolucion del 
practico 3 de la asignatura Practica Profesionalizante 1.

## Instalacion

Instalar previamente uv segun la documentacion oficial:

https://docs.astral.sh/uv/getting-started/installation/

Clonar repositorio

git clone https://github.com/luirro777/persona-oficina

cd persona-oficina/

uv sync

## Ejecutar el proyecto

uv run python -m project.app
